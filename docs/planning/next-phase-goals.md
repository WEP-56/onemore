# Onemore 当前开发目标

更新日期：2026-08-10

## 范围

当前开发目标是浏览器控制。它应提供可观察、可取消、有边界的页面交互能力，并复用现有
runtime、权限、工具输出和 TUI 事件链路。

浏览器控制与现有 Web 搜索是两个独立能力。浏览器工具由 harness 执行，不伪装成 provider
hosted tool，也不在运行失败时切换到其他实现。

## 最小能力

第一版应覆盖：

- 启动或连接受控浏览器，并创建、列出、选择和关闭页面。
- 导航 URL、前进、后退和刷新。
- 获取有界的页面快照，并用稳定元素引用进行点击、输入、选择、滚动和按键操作。
- 截图并返回可定位的 artifact，而不是把二进制内容写进模型上下文。
- 报告当前 URL、标题、加载状态、活动页面和最近一次操作结果。
- 任务取消、session 结束或显式关闭时回收浏览器资源。

工具数量应保持克制。优先使用少量按操作分类的工具和明确的 action 枚举，避免为每个 DOM
动作增加一个几乎相同的工具。

## 运行时与数据边界

- 浏览器实例和页面句柄由 harness 管理，使用 session 内稳定且不可伪造的 ID。
- 模型只使用最近快照返回的元素引用；导航或页面显著变化后，旧引用必须明确失效。
- 页面快照、控制台输出、网络摘要和截图元数据都必须有大小与数量上限。
- 工具结果继续使用 `ToolOutput { model_text, ui_summary, details }`，模型正文只保留完成下一步所需内容。
- 浏览器进度通过现有 `ToolCallStarted / Updated / Finished` 链路发布；TUI 不维护独立真相源。
- 浏览器资源不进入 session facts 的可重放语义。恢复历史会话时，应明确显示浏览器已断开。

## 权限与安全

- 导航前规范化并校验 URL，只允许明确支持的协议。
- 登录、提交表单、下载、剪贴板、文件选择和可能产生外部副作用的交互必须经过权限评估。
- 页面内容、页面脚本和下载文件都视为不可信输入，不能绕过 workspace 与命令权限。
- 凭据、Cookie 和完整页面存储不得进入模型文本、日志、artifact 名称或持久化 facts。
- 取消必须传播到进行中的导航和交互；超时后不能留下仍在后台继续执行的动作。

## TUI 表现

- transcript 中显示一行有界操作摘要、页面标题和域名。
- 运行中持续更新导航、等待和交互状态，不等整个 loop 结束后才展开。
- 详细参数、耗时、错误和截图路径沿用工具详情面板展示。
- 截图作为 artifact 打开，不在 transcript 中输出大段编码内容。
- 参考 `example/tui` 的布局和交互方式，但状态必须来自 Onemore 的 SDK event 与 snapshot。

## 实施顺序

1. 选定成熟的浏览器自动化引擎，定义 session/page/element 生命周期与安全边界。
2. 实现页面管理、导航、快照和关闭，再加入基于快照引用的交互。
3. 接入截图 artifact、取消、超时、权限与有界输出。
4. 接入 TUI 实时状态和详情展示。
5. 增加 mock/fixture 测试与真实本地页面端到端测试。

## 验收标准

- 可在一次任务中打开本地测试页、导航、读取快照、完成交互、截图并关闭浏览器。
- 页面变化后使用旧元素引用会得到稳定错误，不会误操作其他元素。
- 运行期间能看到当前浏览器动作，任务结束后可查看有界摘要和详情。
- 取消、超时和 session 关闭都不会遗留浏览器进程或继续产生副作用。
- 页面大、控制台噪声多或截图尺寸大时，模型上下文与内存占用仍有明确上限。
- TUI、`--once`、SDK 和 RPC 继续使用同一个 runtime 事实与事件源。

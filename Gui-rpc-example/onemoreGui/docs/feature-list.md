# OnemoreGui 功能列表(基于 desktop-cc-gui 参考)

> **状态:2026-08 已完成首轮实施。** 下方标注 [适配]/[复用] 的条目均已实现。
>
> 调研结论:
> - desktop-cc-gui 前端约 6.7 万行 + Rust 后端约 23 万行,onemoreGui 目前约 2300 行,整体照搬不可行。
> - 复用策略:**视觉规范**(主题 token / CSS)、**布局结构**(三栏 + 顶栏 + 输入框)、**核心交互模式**(卡片式消息、tool 卡片、审批、@引用、队列)按 cc-gui 实现;数据层保持 onemore RPC 协议与现有 Rust 桥。
> - 标注说明:
>   - **[复用]** = 可直接借鉴 cc-gui 的组件/CSS 代码
>   - **[适配]** = 视觉/结构照抄,但数据层需对接 onemore RPC
>   - **[跳过]** = 依赖 cc-gui 特有后端或 onemore 协议不支持

## 8. 设置中心(Settings)— 重大调整

> 设置大类改为:
> 1. **基础设置**:仅外观调整
> 2. **配置**:可视化调整 onemore 的 config.toml(参考 `E:\onemore-cli\config.example.toml`)
> 3. **项目**:项目(工作区)管理
> 4. **会话**:会话管理
>
> **删除**:快捷键设置、skill、社区、智能体、扩展、市场、面板模式

| # | 功能 | 说明 | 标注 |
|---|------|------|------|
| 8.1 | 设置窗口框架 | 左侧导航 + 右侧分区(cc-gui settings.part2 视觉) | [复用] |
| 8.2 | **基础设置** = 外观调整 | 主题(默认/跟随系统/浅色/深色)、用户消息颜色、UI 缩放、UI/代码字体。**不做**窗口透明度/毛玻璃 | [适配] |
| 8.3 | **配置** = 可视化 config.toml | 覆盖 agent、retry、compaction、permissions、providers/models、Web 搜索（位置/域名/外部厂商凭据）和 MCP servers（启动/环境/超时/审批/工具过滤）；保留原始 TOML 编辑。保存仅影响新建或重启的 RPC 任务 | [适配] |
